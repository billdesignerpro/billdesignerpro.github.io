# Bill Designer Pro Website

Static website for Bill Designer Pro, a demo and project-enquiry service for customized Android invoice apps for businesses.

## Pages
- `index.html` — Overview, introductory pricing and enquiry CTA
- `features.html` — Features and customization options
- `about.html` — How a custom app project works
- `contact.html` — Enquiry contact details
- `privacy-policy.html` — Website/app privacy policy draft
- `terms.html` — Website/project terms draft

## Deployment
This website is configured for the custom domain `billdesigner.in` through GitHub Pages. Keep the `CNAME` file and verify GitHub Pages settings after any repository transfer.

## Before public launch
- Review the privacy policy and terms against the production app, actual data practices, and applicable law.
- Confirm introductory offer availability, project scope, taxes/third-party costs and written quotation terms.
- Add a real app-store/download link only when distribution is available.
- Test all pages, navigation, WhatsApp contact, mobile layout, HTTPS and custom-domain DNS after deployment.


## Version v4 — mobile responsiveness and central configuration
- `assets/config.js` contains editable pricing, contact email, phone/WhatsApp number, website URL, offer wording and site version.
- Update values in `assets/config.js` to change common website details without editing every page.
- The website includes responsive mobile refinements; test on real phones and after GitHub Pages deployment.
